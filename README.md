 Problem Solving with TypeScript & OOP

 Assignment Overview

This repository contains my solutions for the Module 4 Assignment-1 on Problem Solving with TypeScript and OOP.

The main purpose of this assignment is to improve my practical knowledge of TypeScript, including functions, types, generics, interfaces, promises, and Object-Oriented Programming.

Technologies Used

 JavaScript
 Object-Oriented Programming (OOP)

All eight coding problems are solved in a single file named solutions.ts.

 Optional Parameters and Default Values

Readonly Tuples
 Generics and Rest Parameters
Interfaces and Array Filtering
